# S2Arm 常见问题

- 第一次用请先看[使用教程](内测教程.md)。
- 屏幕上出现了报错，请到[故障排除](故障排除.md)里按提示文字搜索。

---

## 基本问题

### S2Arm 是做什么的？

把**你自己的** Switch 游戏，在 Mac 上打包成能在 Mac、iPhone、iPad 上运行的版本。打包完成后，在 Mac 上可以直接玩；如果想在手机或平板上玩，就把打好的包装上去。

### 要钱吗？

S2Arm 本身免费。装到 iPhone 时要用的 Apple ID 用免费账号就行，但免费账号有一些限制，见下面的 [7 天过期](#为什么装好的游戏过几天就打不开了)和[最多 3 个](#一台-iphone-能装几款游戏)。

### 你们提供游戏、密钥或固件吗？

**不提供，也不会帮你下载。** 你需要自己准备两样东西：

- **prod.keys**：你自己的密钥文件，导入即可；
- **游戏文件**：从你有权使用的游戏导出的 NSP 或 XCI（本体必须有，更新和 DLC 有就一起放）。

S2Arm 只用在你自己的电脑上，不提供、也不分发这些内容。

### 我的密钥和游戏会被上传吗？

不会。密钥和游戏只保存在你自己的 Mac 上。诊断包里也只有运行日志，不含密钥、游戏文件和存档。

### 支持所有 Switch 游戏吗？

还不能保证。

- 目前只支持 64 位的游戏，少数 32 位的老游戏打不了包。
- 能打包、能打开、能进游戏、画面正常、能长时间稳定玩，这几件事要分别验证。某款游戏在一台设备上能玩，不代表在别的机型或别的游戏版本上也一样。

遇到问题欢迎[回报](故障排除.md#怎么回报问题)，这对我们帮助很大。

## 设备和系统

### 需要什么设备？

| 想做什么 | 需要 |
|---|---|
| 打包（所有用法都要先打包） | Apple 芯片的 Mac（M1 起），**macOS 26 或更新**，装好免费的 Xcode；或者 Windows 电脑（用 Windows 启动器，只能给 iPhone / iPad 出包） |
| 在 Mac 上玩 | 同上 |
| 在 iPhone 上玩 | A14 或更新的芯片（iPhone 12 起），**iOS 18 或更新** |
| 在 iPad 上玩 | A14 / M1 或更新的芯片，**iPadOS 18 或更新** |

- **iOS / iPadOS 26 及以上**：效果最好，也是目前验证最多的。
- **iOS / iPadOS 18 到 25**：用的是兼容方式，目前主要在 Mac 上验证过，真机还缺数据。部分游戏在这些系统上打包时，会提示需要 iOS 26。欢迎回报你的实际运行情况。

> 📷 截图待补：iPhone「设置 → 通用 → 关于本机」里看系统版本和型号的位置（建议文件名 `images/常见问题/01-关于本机.jpg`）。

### 我的 Mac 是 macOS 15 / Intel 芯片，能用吗？

- **Mac 上的 S2Arm 应用需要 macOS 26 或更新、Apple 芯片**，旧系统上打不开。旧系统的支持还在推进中。
- 如果只想给 iPhone 出包：Intel Mac 或旧系统可以用命令行出包，见[使用教程第一节](内测教程.md#一你需要准备的东西)。这条路需要一些电脑操作经验。

### 能在 Windows 或安卓上用吗？

- **Windows**：可以给 iPhone / iPad 出包并装机。从[下载页](https://jhaizhou-ops.github.io/S2Arm/)下载 Windows 启动器，签名装机用它附带的 Impactor。但 Windows 上不能直接玩游戏，「在 Mac 上玩」也只有 Apple 芯片的 Mac 能用。
- **安卓**：还在开发中，暂时不能给普通玩家用。

### 一个包能装到好几台设备上吗？

可以装，但不推荐。打 iPhone 包时，S2Arm 会**按你选的那台设备的型号和系统版本**提前准备好画面。装到别的型号或别的系统大版本上也能打开，但玩的时候会边玩边准备，就会变卡。

每台设备最好各打一次包。换手机、或者大版本升级（比如从 iOS 26 升到 27）之后，也请重新打一次。

## 打包

### 为什么第一次打包这么久？

S2Arm 会把游戏的画面程序（着色器）**全部提前编好**，这样玩的时候就不会一卡一卡的。大型游戏在 MacBook Air 上第一次可能要一个多小时。

- 请插上电源，别让 Mac 睡眠。
- 之后再打包同一款游戏，会快很多。

### 打包要占多少空间？

大约是游戏本身大小的一到两倍（0.1.0 beta.4 起游戏文件留在原处、不再复制进游戏库；占的是解包内容、打好的版本和提前编好的画面，比如 16.9 GB 的索尼克×夏特导出 iPhone 版后游戏库约 28 GB）。游戏文件本身放在哪块盘都行，exFAT 外接盘也可以。打 iPhone 包时，第一次还要额外下载约 2 GB 的工具。放游戏前请留出足够的空间；空间不够时，S2Arm 会提示需要多少、还剩多少。

### 可以一次放好几款游戏吗？

可以。它们会排队，一款打完再打下一款。

### S2Arm 更新以后，要重新打包吗？

建议重新打包。新版本的修复和改进，通常要重新打包后才会生效。存档不受影响。

## 装到 iPhone / iPad

### 怎么装到 iPhone？

有两种方法，详见[使用教程第八节](内测教程.md#八装到-iphone)：

- **S2Arm 的「装到 iPhone」**：用 Xcode 里登录的 Apple ID 签名，数据线连着就能一步装好，资源包也会自动拷进去；
- **AltStore**：把打好的 `.ipa` 文件用 AltStore 装上，资源包再自己拷进去。

**不要用 SideStore 0.7.0**：它会丢掉大型游戏需要的「提高内存上限」权限，游戏会因为内存不够打不开。

**游戏包很大时，优先用数据线**：AltStore 走 Wi-Fi 传大包容易中断，有 2 GB 以上传输崩溃的个案报告；「装到 iPhone」走数据线，没有这个问题。**TrollStore 用不了**：它只支持到 iOS 17.0，而 S2Arm 需要 iOS 18 或更新。

### 为什么装好的游戏过几天就打不开了？

用**免费 Apple ID** 装的 App，**7 天后过期**，这是苹果的规定。

- **存档不会丢**，续签以后就能接着玩，也不用重新拷资源包；
- 用 AltStore 装的，会在后台自动续签，也可以手动点「刷新全部」；
- 用「装到 iPhone」装的，到期后连上手机再点一次就行。

离到期不到 2 天时，游戏画面顶部会提示一次。付费的苹果开发者账号签的 App，一年才过期。

### 一台 iPhone 能装几款游戏？

用免费 Apple ID，**每台 iPhone 同时最多 3 个自签 App**（AltStore 这类侧载工具自己也占 1 个，用它时只剩 2 款游戏），**每 7 天最多注册 10 个新 App**，**一个 Apple ID 最多给 3 台设备签名**。这些是苹果对免费账号的规定。请先挑最想玩的装。

### 为什么除了 App 还要拷一个「资源包」？

游戏数据很大，所以分成两部分：App 里只有程序，游戏本身的数据在「资源包」里。第一次打开时，App 会把资源包导入进去，要等几分钟，期间**别切走、别锁屏**。导入完成后会自动进入游戏（0.1.0 beta.3 起；更早的包导入完要从后台划掉 App 再重新打开）。

## 游玩

### 存档在哪里？能备份吗？

- **Mac**：每款游戏的存档分开保存在游戏库里。在游戏详情页点「存档备份与恢复…」，可以把存档导出成一个备份文件，也可以从备份恢复。
- **iPhone**：存档在这款游戏的 App 里面。删掉 App 会连存档一起删掉，过期则不会。
- **把 Switch 上的存档搬过来**：目前还没有面向玩家的一键导入，相关功能在开发中。

### 能用手柄吗？

可以。

- iPhone / iPad 支持系统认得的蓝牙手柄，比如 Xbox、PlayStation、Switch Pro 手柄。
- 没有手柄时，屏幕上有触屏按键。
- Switch 2 Pro 手柄要在这款游戏的「设置」里单独打开适配，见[手柄说明](../runtime/ns2pro/README.md)。
- Mac 上可以在「键鼠与手柄映射」里改按键。

### 画面能调吗？怎么让它更流畅或更清晰？

在 iPhone 的「设置」里找到这款游戏的 App，可以调分辨率倍率、抗锯齿和帧率上限。改完要从后台划掉游戏，再重新打开才生效。

- 分辨率调高，画面更清晰，但更耗电、更热；
- 低配设备建议保持默认。

详见[画面设置](画面设置.md)。

### 游戏语言怎么改？

默认跟这台设备的系统语言；游戏没有这种语言时显示英文，英文也没有就用游戏自己的默认语言。

- **iPhone / iPad**：游戏里打开设置，在「语言」里改「游戏语言」，下次打开这款游戏生效。在 App 里选过「界面语言」的，游戏默认跟界面语言。
- **Mac**：点「开始游戏」旁的齿轮，打开启动设置，改「游戏语言」，下次启动生效。

每款游戏单独记，不用重新打包。

### 从 Switch 导入存档后，角色名字显示乱码？

有的游戏按系统语言整套换字体。Switch 上用日文、韩文或中文起的名字，换到另一种语言的字体里就显示不出来。把这款游戏的「游戏语言」改成当时 Switch 用的语言即可（改法见上一条）；存档本身没有坏。

### 能联机吗？

Switch 游戏里的「联机」分三种，S2Arm 的情况不同：

- **本地无线（几台机器面对面一起玩）**：还在开发中，目前不能用。做好以后需要几台设备连**同一个 Wi-Fi 或同一个个人热点**；没有路由器、设备之间直接连的方式暂不支持。
- **游戏菜单里的「LAN 模式」**：不支持。
- **在线功能（Nintendo Switch Online、联网对战、排行榜等）**：不支持。

### 能接电视玩吗？

iOS 27 起，用转接线把 iPhone 接到显示器或电视，进游戏后游戏画面单独输出到这块屏上、按它的分辨率铺满，手机屏留给触屏手柄；拔掉后画面回到手机。游戏库和加载页仍是**镜像**（和手机上一样）。

iOS 26 及更早只能镜像。AirPlay 和 iPad 还没验证过单独输出。

### 能让 AI 助手帮我操作吗？

可以。在 Mac 上 S2Arm 的「设置 → 用 AI 操作」打开开关，AI 助手就能替你放密钥、放游戏、打包、看失败原因。详见[使用教程](内测教程.md#让-ai-帮你做可选)。
