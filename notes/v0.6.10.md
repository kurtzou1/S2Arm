# S2Arm v0.6.10

这一版主修联机和声音：联机自动模式在 iPhone / iPad 上能发现房间，与 Switch 联机请在联机设置里选「与 Switch 联机」；Mac 插拔耳机、切换输出设备后声音不再一直慢半拍；Switch 2 游戏接上真实麦克风；同一个包里装了 36 位和 39 位地址的两款游戏时都能起。
*This release mainly fixes local multiplayer and audio: auto mode now finds rooms on iPhone / iPad (to play with a Switch, choose "Play with Switch" in the multiplayer settings); on Mac, sound no longer stays behind after plugging or unplugging headphones or switching the output device; Switch 2 games get a real microphone; a package holding two games with 36-bit and 39-bit address spaces can start both.*

## 新增
- **Switch 2 游戏的麦克风输入**：Mac 与 iOS 接上真实麦克风，开 / 关哼唱识别不再崩（#2151）。
  *Microphone input for Switch 2 games: Mac and iOS use the real microphone, and turning humming recognition on or off no longer crashes (#2151).*
- **iOS 分屏「自动」成为缺省**：竖着拿手机且上半区放得下画面时，自动上下分屏，按键都在下半区，不再叠在画面上；横过来照旧横屏排布（#2179）。
  *iOS split screen now defaults to "Auto": held upright with room for the picture in the top half, the screen splits top and bottom with all buttons in the lower half instead of covering the picture; in landscape the layout is unchanged (#2179).*
- **诊断码**：帖子里给的诊断码粘进电脑启动器，下次推那款时写进手机，生效一局后自动撤掉，iPhone 玩家也能开诊断。
  *Diagnostic codes: paste a code from an issue into the computer launcher; it is written to the phone with the next push of that game, applies for one session and then removes itself, so iPhone players can turn on diagnostics too.*
- **Apple ID 签名可以沿用导入的 .p12 证书**，不新建证书，也不撤掉 SideStore 的证书（#2015）。
  *Apple ID signing can reuse an imported .p12 certificate, without creating a new one or revoking SideStore's (#2015).*
- **Mac 启动器按钮样式统一**：同一排按钮形制一致，不再有胶囊破图（#2030，感谢 nevenhsu）。
  *Mac launcher buttons share one style: buttons in a row match and pill shapes no longer break (#2030, thanks to nevenhsu).*

## 修复
- **联机**：自动模式在 iPhone / iPad 上照常「发现 → 中继」，能搜到、能进同一房间；握手按会话路由，多网卡 / VPN 时选对网卡（#2134，感谢 maiga512）。与 Switch 联机请在联机设置里选「与 Switch 联机」。
  *Multiplayer: auto mode on iPhone / iPad discovers rooms and relays as before, so players can find and join the same room; handshakes are routed per session and the right network adapter is chosen with several adapters or a VPN (#2134, thanks to maiga512). To play with a Switch, choose "Play with Switch" in the multiplayer settings.*
- **声音**：Mac 插拔耳机或切换输出设备后，声音不再永久滞后（#1819）；切换音频路由后游戏不再中止；部分游戏刷新音频缓冲后宿主不再闪退；游戏设置外部音频流增益不再报错中止。
  *Audio: on Mac, sound no longer stays permanently delayed after plugging or unplugging headphones or switching the output device (#1819); games no longer abort after the audio route changes; flushing audio buffers in some games no longer crashes the host; setting the gain of an external audio stream no longer aborts.*
- **同一个包里装了 36 位和 39 位地址两款游戏时，选中的那款按它自己的地址窗口起局**，两款都能玩。
  *In a package holding a 36-bit and a 39-bit game, the selected game starts with its own address window, so both can be played.*
- **大内存池游戏显存占用下降**：大池改成整池一个缓冲后，旧的分块按期放掉，不再把 GPU 显存顶满后闪退（#2131，感谢 imneway）。
  *Lower GPU memory in games with large memory pools: after a large pool switches to one whole-pool buffer, the old chunks are released on schedule instead of filling GPU memory until a crash (#2131, thanks to imneway).*
- **补帧**：插值器重建时先等在途命令做完再释放，不再 GPU 缺页闪退。
  *Frame interpolation: when the interpolator is rebuilt it waits for in-flight commands before releasing, so it no longer crashes with a GPU page fault.*
- **S2Arm 更新后，本机现编过的着色器按单支重译，不再整批作废**；旧版出的「离线 0 支」iPhone 包会提示更新这款（#2158）。
  *After an S2Arm update, shaders compiled on this device are retranslated one by one instead of being thrown away as a batch; iPhone packages built by older versions with zero offline shaders now suggest updating the game (#2158).*
- **iPhone / iPad 读即时快照后不再卡在第一帧**（设备重启后也是，#2124，感谢 imneway）；即时存档与前后台切换的冻结互不干扰。
  *Reading a snapshot on iPhone / iPad no longer sticks on the first frame, including after a device restart (#2124, thanks to imneway); snapshot freezing and background freezing no longer release each other.*
- **换了装 App 的工具后，电脑不再一直提示「更新 iPhone 上的 S2Arm」**（#2160）；手机上的 S2Arm 是别的工具装的、又比启动器旧时，提示指向总控台上的「导出 S2Arm.ipa」。
  *After switching the tool used to install the app, the computer no longer keeps asking to "Update S2Arm on iPhone" (#2160); when the phone's S2Arm was installed by another tool and is older than the launcher, the notice points to "Export S2Arm.ipa" in the console.*
- **装机前备份手机存档快了很多**：整个存档目录一次拉回，不再逐文件拉。
  *Backing up phone saves before installing is much faster: the whole save folder is pulled at once instead of file by file.*
- **iOS 存档管理能选文件夹导入了**（JKSV 等导出的文件夹）。
  *iOS save management can import a whole folder (such as a JKSV export).*
- **Mac 上只用手柄玩时不再到点锁屏**（#2159）；Mac 菜单 / 启动台不再出现一排「S2Arm Game」（#2024）。
  *On Mac, playing with only a controller no longer lets the screen lock (#2159); the Mac menu and Launchpad no longer show a row of "S2Arm Game" entries (#2024).*
- **手柄与体感**：iOS 手柄体感改在主线程开关，全零空样本退回手机陀螺仪；Joy-Con 体感方向与单只右 Joy-Con 的传感器槽位修正（感谢 nevenhsu）；「分配玩家」里一位都没登记时手柄不再全部失去玩家位。
  *Controllers and motion: iOS controller motion is switched on the main thread and all-zero samples fall back to the phone gyroscope; Joy-Con motion direction and the sensor slot of a single right Joy-Con are fixed (thanks to nevenhsu); with no player registered in "Assign players", controllers no longer all lose their player slot.*
- **出包与导出**：先出 iPhone 包再导出 .s2arm 的款不再重新出包；导出最后一步的步数显示正常；.s2arm 导入与后台解开不再互相删文件；推包时核对机上文件长度，不对就重传；LiveContainer 里证书用不上时提示导入证书。
  *Building and exporting: a game built for iPhone and then exported as .s2arm is no longer rebuilt; the step count of the last export step displays correctly; importing a .s2arm no longer deletes files being unpacked in the background; pushing verifies file sizes on the phone and resends mismatches; inside LiveContainer, an unusable certificate prompts you to import one.*
- **Windows**：游戏库里有损坏的封面图时，启动器不再卡在「正在检查这台电脑」打不开，那一格改用占位图；作业的错误输出写不进时不再让整单失败；两处 [Errno 22] 报出真正原因；进度采样崩溃不再打断出包。
  *Windows: a damaged cover image in the game library no longer leaves the launcher stuck at "Checking this computer"; that tile shows a placeholder instead; a job no longer fails just because its error output could not be written; two [Errno 22] errors now show the real cause; a crash in progress sampling no longer interrupts a build.*
- **画面**：部分 GL 游戏着色器改写与离线库修复（#852）；线程组大于 256 的计算着色器声明正确上限；顶点越界读的保护范围放大；按着色器声明限制常量缓冲绑定长度（感谢 n06ody）。
  *Graphics: shader rewriting and the offline library are fixed for some GL games (#852); compute shaders with thread groups over 256 declare the right limit; protection for out-of-range vertex reads covers larger ranges; constant buffer binding lengths follow the shader declarations (thanks to n06ody).*
- **安卓**：离线 Vulkan 库接入内容缓存，同款重出包不再逐键重翻；描述符绑定号 ≥ 256 的程序能建管线；修最新版在安卓上起局黑屏（感谢 n06ody、vickwv、WKkCoder）。
  *Android: offline Vulkan libraries use the content cache so rebuilding the same game no longer retranslates every key; programs with descriptor bindings at 256 or above can build pipelines; fixed a black screen at launch on Android (thanks to n06ody, vickwv and WKkCoder).*
- **Apple TV**：游戏包里没有图标文件的款，点「开始」不再闪退（#1758）。
  *Apple TV: games whose package has no icon file no longer crash when you press Start (#1758).*
- **错误摘要**：导致这一单失败的错误排在前面，警告级写成「提醒」排在后面（#2150）。
  *Error summaries list the errors that failed the job first and show warnings as notes after them (#2150).*
