# S2Arm v0.6.2

这一版可以选「独立 App」出包，一款游戏一个 App、点开直接进游戏；iPhone 上能直接导出这一款；出包更快，后段每一步都能看出在走；修了一批 Windows 出包失败、Apple ID 登录（含部分账号密码正确仍登录失败）和签名到期显示的问题，Mac 启动时不再弹出访问外接磁盘的授权；用 LiveContainer 装的 S2Arm 也能进游戏了，iPhone 上「自动」方向改成跟随系统。
*You can now pack a game as a standalone app, one app per game that opens straight into the game; the iPhone can export a game by itself; packing is faster, and every late step now shows that it is moving. This release fixes a set of Windows packing failures, Apple ID sign-in problems (including some accounts failing with the correct password) and wrong signing expiry dates, and the Mac no longer asks for access to external drives at launch; S2Arm installed through LiveContainer can now start games, and Automatic orientation on iPhone now follows the system.*

## 新功能
- **iPhone：用 LiveContainer 装的 S2Arm 也能进游戏**：S2Arm 装在 LiveContainer 里时，起游戏会用 LiveContainer 里导入的证书给这款游戏的程序重签。以前会报「程序库签名本机不认」进不去。LiveContainer 还没导入证书时，提示页会直接说去 LiveContainer 的设置里导入证书，不再让你改用电脑上的 S2Arm。
  *iPhone: S2Arm installed through LiveContainer can now start games. When S2Arm runs inside LiveContainer, it re-signs the game's program with the certificate imported into LiveContainer. It used to stop with "program library signature not accepted on this device". If LiveContainer has no certificate yet, the message now tells you to import one in LiveContainer's settings instead of telling you to switch to S2Arm on the computer.*
- **Mac：联机模式新增「与 Switch 联机」（社区贡献，#1741）**：设置里「联机模式」多了一项「与 Switch 联机」，选了它可以和装了 ldn_mitm 的 Switch 在同一局域网里联机。缺省仍是「自动」；选了这一项后，不能再用原有方式和 iPhone 或另一台 Mac 联机。改完要完整退出游戏再打开才生效。
  *Mac: new With Switch option in Multiplayer mode (community contribution, #1741). Pick With Switch to play over the local network with a Switch running ldn_mitm. Automatic stays the default; while With Switch is selected, the usual multiplayer with an iPhone or another Mac does not work. Quit the game completely and reopen it for the change to apply.*
- **Mac：游戏里也能拆合一代 Joy-Con（#918）**：进了游戏以后，按 SL + SR 把一对 Joy-Con 拆成两只横握两人玩，两只各按 L / R 再合回一对单人玩，游戏里的玩家数跟着变。以前只有「分配玩家」面板开着时才认这两个手势，进了游戏切不回去。
  *Mac: split and rejoin first-generation Joy-Con during a game (#918). In a game, press SL + SR to split a pair into two sideways controllers for two players, and press L / R on each to join them back into one pair for one player; the game follows. These gestures used to work only while the Assign players panel was open, so you could not switch back once in a game.*
- **Mac：手柄玩家灯、Joy-Con 颜色与按键布局（社区贡献，#1759）**：手柄上的玩家灯按 P1–P8 同步；一代 Joy-Con 显示它自己的颜色；一代 Joy-Con 与 Joy-Con 2 拆合后重连更稳；四键布局可以按手柄分别设，改了在启动器里立刻生效。
  *Mac: controller player lights, Joy-Con colors and button layout (community contribution, #1759). Player lights on the controller now follow P1–P8; first-generation Joy-Con show their own colors; first-generation Joy-Con and Joy-Con 2 reconnect more reliably after splitting or joining; the face-button layout can be set per controller and takes effect in the launcher right away.*
- **Mac：Dock 和 Cmd+Tab 里显示游戏封面（社区贡献，#1779，#994）**：开始游戏后，Dock 和 Cmd+Tab 里显示的是这款游戏的封面，不再是系统的空白图标。
  *Mac: the game's cover in the Dock and Cmd+Tab (community contribution, #1779, #994). Once a game starts, the Dock and Cmd+Tab show its cover instead of the system's blank icon.*
- **Mac / Windows：免费签名到期提醒可以关掉**：游戏库的免费签名到期提醒只跟着手机上启动器用免费 Apple ID 签的那份 S2Arm 走；换成别的工具或别的签名方式装过以后，提醒不再一直挂着。提醒旁边多了「×」可以擦掉，设置里有「免费签名到期提醒」开关，可以重新打开。
  *Mac / Windows: the free-signing expiry reminder can be dismissed. The reminder in the Library now only follows the copy of S2Arm on the phone that the launcher signed with a free Apple ID; after you install it with another tool or another signing method, it no longer stays up. It has an × to dismiss it, and a Free signing expiry reminder switch in Settings turns it back on.*
- **独立 App：一款游戏一个 App**：出包时可以选「独立 App」，这一款装成自己的 App，主屏用游戏的名字和图标，点开直接进游戏，不经过游戏库。也可以照旧用「通用壳」。用分发证书签名时默认独立 App，其余默认通用壳；单款可以另选，你选过的优先。总控台每台手机下多了「独立 App」一节，列出每款的签名剩余天数；「更新所选」「从手机删一款」都按出法分开处理。选出法是两张并排卡片，各一句说清是什么，按你的签名方式标出推荐，问号里讲原理；选了不推荐的那张，卡片下方出一行橙字说后果（比如分发证书选通用壳游戏打不开、免费 Apple ID 选独立 App 最多 3 个 App 且 7 天要续签），只提示不拦。装好或导出后，成功页写清装到哪台、手机上的名字、到期时间；导出的独立 App 放在这款的游戏文件夹里，附一份按界面语言写的说明（请先读我.txt / README.txt），照着下一步做就行。
  *Standalone app: one app per game. When packing you can choose Standalone app: the game installs as its own app with its name and icon and opens straight into the game. The universal shell still works. Two cards side by side show both options, mark the one recommended for your signing method and explain why; picking the other shows an orange line saying what will happen, without blocking. Distribution certificates default to Standalone app, everything else to the universal shell, and your choice per game wins. The success page shows the phone, the name on the phone and the expiry date; an exported standalone app goes into the game's folder with a read-me in your language. The phone console lists standalone apps with their remaining signing days.*
- **iPhone：长按游戏「导出这一款…」（#1793）**：在 iPhone 的游戏库里长按一款，选「导出这一款…」，手机上直接生成 .s2arm 和 .img 两个文件交给「文件」App，可以拷给别人或留作备份。电脑推送装的款也能导出。
  *iPhone: long-press a game and choose Export this game… (#1793). The iPhone creates the .s2arm and .img files for that game and hands them to the Files app, to share or keep as a backup. Games installed by pushing from the computer can be exported too.*
- **iPhone / Mac：地址空间不够这款时先说明**：开局时如果判出这款游戏在这台设备上地址空间不够（可能很卡或停在开头），iPhone 上会先给一页说明，可以点「仍要启动」照常进游戏，不拦；Mac 上在游戏窗口之上弹一条提示，不挡游戏。
  *iPhone / Mac: a notice when the device's address space is too small for a game. If S2Arm detects at launch that a game will not fit the device's address space (it may run very slowly or stop at the start), the iPhone shows a page explaining this and Start anyway launches the game as usual; on the Mac a notice appears above the game window without blocking the game.*

## 改进
- **出包更快**：编译着色器库的后几段改成把同类着色器合在一起编（一款大作原先这两段逐个编要几分钟），并按电脑此刻的空闲内存随时多开并行，不再整段按出包开头那一刻定死；已经出过包的游戏再出包时，「拉取基础管线」这段先查缓存（一款大作原先这段仍要四分多钟）。（#1723、#1770）
  *Faster packing. The late stages of building the shader library now compile similar shaders together (one large game used to spend several minutes compiling them one by one), and add more parallel work whenever memory frees up instead of fixing it at the start of packing. When packing a game again, the base pipeline step checks the cache first (it used to take over four minutes for one large game even then). (#1723, #1770)*
- **Mac / Windows：出包页能看出是不是真卡住**：编译着色器库的后几段每一步都有计数，不再停在 100% 看不出后台在走；当前步骤旁边显示「上次前进 N 秒前」，计数不动、这个数又一直在涨，才是真卡住。（#1723、#1770、#1773）
  *Mac / Windows: the packing page shows whether it is really stuck. Every late step of building the shader library now has a counter, so it no longer sits at 100% with no sign of progress, and the current step shows "last moved N seconds ago". It is only really stuck if the counter stays put while that number keeps growing. (#1723, #1770, #1773)*
- **Mac / Windows：抽取开工前不再停半分钟不动**：出包「抽取」开始前要先核对游戏文件，这一步原先在冷缓存时 24–35 秒没有任何进度，现在逐个文件计数。因为这一步的记录方式变了，每款游戏升级后第一次出包会重新抽取一次，之后照常。
  *Mac / Windows: no more half a minute without progress before extraction. Before the extract step starts, packing checks the game's files; with a cold cache this showed no progress for 24–35 seconds, and it now counts file by file. Because this step now records its work differently, each game re-runs extraction once the first time you pack it after updating; after that it behaves as before.*
- **Mac / Windows：同一款不会重复推到 iPhone**：一款正在推或在排队时，它的「推到 iPhone」按钮显示「推送中… / 排队中」并变灰，不会再点一下又排一单、推完再推一遍。
  *Mac / Windows: a game is no longer pushed to the iPhone twice. While a game is being pushed or waiting in the queue, its Push to iPhone button says Pushing… / Queued and is greyed out, so an extra tap no longer queues a second push.*
- **进新场景更少卡一下**：出包时能预编的管线全部随包，不再按原件 10% 的体积封顶（一款游戏序章用到的 181 组里，原先只有 44 组随包）。代价是包更大、这一步更久：同一款随包内容从 464 MB 变成 1,422 MB。
  *Fewer hitches entering new scenes. Every pipeline that can be prebuilt during packing is now included, no longer capped at 10% of the original game's size (in one game only 44 of the 181 pipelines used in the prologue used to be included). The cost is a larger package and a longer step: that game's bundled data went from 464 MB to 1,422 MB.*
- **社区与公开清单里的管线重新用得上，iPhone 上玩过的场景也会预编**：0.6.0 起，社区收集的和公开项目清单里的着色器管线在出包时一条都对不上、全被丢掉；现在会先换算再用（一款游戏从 0 条变成近 2,000 条）。重新出包时，你在 iPhone 上真玩到过的管线也会排在最前面预编。
  *Pipelines from the community and public lists work again, and scenes you played on iPhone get prebuilt. Since 0.6.0, shader pipelines collected by the community and from public project lists never matched at packing time and were all dropped; they are now converted first (one game went from 0 to nearly 2,000). When you pack a game again, pipelines the game actually used on your iPhone are prebuilt first.*
- **出包失败时直接写出原因**：以前很多出包失败的错误摘要只有一句「出包未完成」，原因要翻日志；现在失败那一步的原话会写进红色那一行和错误摘要。（#1725、#1730、#1744）
  *Packing failures now show the reason. Many failed packs used to say only "packing did not finish", with the reason buried in the log; the original message from the failing step now goes into the red line and the error summary. (#1725, #1730, #1744)*
- **iPhone：「自动」方向跟随系统**：方向选「自动」时，系统转到哪个方向画面就排到哪个方向，开了分屏也一样；系统不给倒过来的竖屏时，S2Arm 自己把整个画面（含触控和弹出的设置页）转过来。可折叠的双屏 iPhone 反复开合，画面不再越来越偏。选「横屏 / 竖屏」仍然锁定。
  *iPhone: Automatic orientation follows the system. With orientation set to Automatic, the game lays out in whatever direction the system turns to, split screen included; where the system does not offer upside-down portrait, S2Arm turns the whole screen itself, touch and settings sheets included. On foldable dual-screen iPhones, opening and closing repeatedly no longer shifts the picture a bit more each time. Landscape and Portrait still lock the orientation.*
- **iPhone：大幅减少闪存写入**：部分游戏在内存较小的 iPhone 上会持续写闪存（一款 Switch 1 游戏在 8 GB 机型上每 10 秒写 2–3.5 GB）。现在先用内存，超出这台手机余量的部分才写进文件。
  *iPhone: far less writing to storage. Some games kept writing to the iPhone's storage on models with less memory (one Switch 1 game wrote 2–3.5 GB every 10 seconds on an 8 GB model). Memory is now used first, and only what exceeds this phone's headroom goes to a file.*
- **Mac / Windows：证书体检逐项列出缺的权限（#1760）**：导入开发者证书时，S2Arm 要的三项权限逐条核，缺哪项列哪项、说清后果。分发 / Ad Hoc / 企业证书缺「调试权限」，签出来的 S2Arm 打不开任何游戏，现在导入时直接拒绝、原有证书保留，并给一段可以复制给证书发放人的话，或一键改用 Apple ID 登录。用这类证书签的 S2Arm 在 iPhone 上起游戏被拒时，提示页也会点名缺调试权限。
  *Mac / Windows: the certificate check lists each missing entitlement (#1760). When you import a developer certificate, the three entitlements S2Arm needs are checked one by one, and each missing one is listed with what it breaks. Distribution, Ad Hoc and enterprise certificates lack the debugging entitlement, so S2Arm signed with them cannot open any game; such imports are now refused, your existing certificate is kept, and you get text to copy to whoever issued the certificate, or a one-click switch to Apple ID sign-in. If S2Arm signed this way is refused when starting a game on iPhone, the message also names the missing debugging entitlement.*
- **续签说明指向正确的入口**：免费 Apple ID 7 天到期、或「提高内存上限」权限丢了时，说明改成指向游戏库第一格「S2Arm」里的「续签 S2Arm」，不再让你重新推游戏。
  *Renewal instructions point to the right place. When a free Apple ID's 7 days run out, or the Increased Memory Limit entitlement is lost, the instructions now point to Renew S2Arm in the S2Arm tile at the start of the Library instead of telling you to push the game again.*
- **Mac：设置页与出包页的界面（社区贡献，#1537）**：设置弹窗垂直居中、分成四个标签；出包页和作业页的背景改用当前游戏的模糊海报；收藏按钮改成珊瑚粉；按钮悬停效果更柔和。
  *Mac: Settings and packing page design (community contribution, #1537). The Settings window is centred and split into four tabs; the packing and job pages use a blurred poster of the current game as background; the favourite button is now coral; button hover effects are softer.*

## 修复
- **修复部分游戏离线运行约 80 秒后画面卡住（#1823）**：没联网时，有的游戏会反复提交联网请求、等它出结果，原先这一步回得和真机不一样，游戏线程在这里空转，约 80 秒后画面停住（报告见于《哈迪斯》）。现在离线时的回应顺序与真机一致。
  *Fixed some games freezing about 80 seconds in while offline (#1823). Without a network connection, some games keep submitting a network request and wait for its result; S2Arm answered differently from a real console, the game thread spun there and the picture froze after about 80 seconds (reported with Hades). The offline answers now follow the real console's order.*
- **Windows：写游戏镜像时被别的程序占着文件不再整单失败**：出包写 game.img 时，如果杀毒软件或索引程序正拿着这个文件，原先会在中途报「Permission denied」整单失败；现在这一步照常写完，只是少省一点临时空间，真失败时日志会写明是哪一步。磁盘写满导致的失败，现在直接报「空间不够」。
  *Windows: writing the game image no longer fails because another program holds the file. If antivirus or indexing software had game.img open while packing, writing it used to stop midway with "Permission denied"; it now finishes the write and only saves a little less temporary space, and a real failure names the step in the log. Failures caused by a full disk are now reported as out of space.*
- **图形接口判不出时提示更准**：遇到判不出用哪种图形接口的游戏，提示不再说「多见于自制或移植的程序」，日志里带上定因用的读数，方便报修。
  *A more accurate message when the graphics API cannot be determined. It no longer says this is "common with homebrew or ported programs", and the log now includes the readings used to diagnose it, which helps bug reports.*
- **修复部分 Apple ID 密码正确仍登录失败（#1794）**：一部分 Apple ID 登录时，苹果要求另一种密码校验方式，随包的签名工具原先不支持，密码输对也报登录失败（-22406），App 装不上。现在 Mac、Windows 随包的签名工具都支持这种方式，这类账号能正常登录、安装。
  *Fixed some Apple IDs failing to sign in with the correct password (#1794). For some accounts Apple asks for a different password check that the bundled signing tool did not support, so sign-in failed with -22406 even with the right password and the app could not be installed. The signing tool bundled on Mac and Windows now supports it.*
- **修复启动时弹出访问外接磁盘授权（Mac）**：接着外接硬盘时，S2Arm 一打开就弹出系统窗口「想访问可移除卷上的文件」，原因是每次都去外接盘上找 Xcode。现在只在真正用到 Xcode 时才找，也不再自动翻外接盘；Xcode 装在外接盘上的，可以在设置里自己选。
  *Mac: no more prompt to access an external drive at launch. With an external drive connected, S2Arm asked to access files on a removable volume as soon as it opened, because it searched external drives for Xcode every time. It now looks for Xcode only when actually needed and no longer searches external drives on its own; if Xcode is on an external drive, choose it in Settings.*
- **Mac / Windows：官网更新信息没跟上时也能看到新版**：检查更新时，如果官网上的版本信息还停在旧版，会再看 GitHub 发布页上同一份签名清单，取较新的那个。
  *Mac / Windows: new versions show up even when the website lags behind. If the website's update information is still on an older version, the update check also reads the same signed manifest from the GitHub release and uses the newer one.*
- **即时存档的几处闪退**：存档线程退出时没回收资源，长时间玩会把一块内存区用光、整局退出；部分设备上地址窗口放不下标准布局时，快照占用的区域会挤坏游戏。现在都修好了；实在放不下时这一局关掉快照，游戏照常玩。
  *Several quick-save crashes. The save thread did not release its resources on exit, so long sessions could use up a memory region and end the game; on some devices, when the address window could not fit the standard layout, the snapshot area crowded the game. Both are fixed; if it truly cannot fit, snapshots are turned off for that session and the game runs as usual.*
- **帧率档位降到 30 帧时画面两倍速（#1766）**：档位梯子压回 30 帧档时，出图现在封顶 30 帧，不再两倍速。
  *Double-speed picture after dropping to the 30 fps tier (#1766). When the frame rate ladder steps back to 30 fps, output is now capped at 30 fps instead of running at double speed.*
- **S 级批量升级的进度会倒退**：进度现在只增不减。
  *S-grade batch upgrade progress went backwards. It now only moves forward.*
- **Windows：装机卡片的「详细过程」点开后自己收起**：进度刷新时不再把它收起来。
  *Windows: Details on the install card closed by itself. Progress updates no longer collapse it.*
- **Mac：冒用 Joy-Con 型号的第三方 Pro 手柄认错**：现在按 Pro 手柄识别。
  *Mac: third-party Pro controllers that report a Joy-Con product ID were misidentified. They are now treated as Pro controllers.*
- **老导入的分发证书认不出**：分发证书改成按存着的描述文件现算，以前导入的证书也认得出。
  *Distribution certificates imported earlier were not recognized. They are now checked against the stored provisioning profile, so older imports are recognized.*
- **声音输出起不来或中途断开时游戏退出**：现在改成无声继续，游戏照常跑。
  *The game quit when audio output could not start or dropped out. It now continues without sound.*
- **Windows：「更新所选」里有游戏没推成，会写明原因并可只重试没推成的（兑现 0.6.1 说明）**：iPhone 总控台里「更新所选」有游戏没推成时，现在会在「更新所选」下面写明几款没推成，逐款列出游戏名和原因；点「重试」只重推没成的那几款，推成功的不再重推。原因是「这台手机装着不止一个 S2Arm」时，会直接列出手机上的几个 S2Arm，选一个就记住并自动重推。
  *Windows: Update selected now explains games that did not make it and retries only those (as promised in the 0.6.1 notes). When some games in Update selected in the phone console fail to push, the console now says how many did not make it, listing each game with its reason; Retry pushes only those games again, not the ones that already succeeded. If the reason is that the phone has more than one S2Arm installed, it lists them right there; pick one and it is remembered and the push runs again.*
- **Windows：部分电脑出包一开始就失败（#1762）**：出包的「抽取」和「编译着色器库」两步不再经过随包的 Git Bash，在 Git Bash 起不了子进程的电脑上也能出包。如果是因为系统里开着「强制 ASLR」导致别的步骤起不了子进程，现在会点名这个原因和去哪里关。
  *Windows: packing failing right at the start on some PCs (#1762). The extract and shader library steps no longer go through the bundled Git Bash, so packing works on PCs where Git Bash cannot start child processes. If another step fails because Mandatory ASLR is turned on in Windows, the launcher now names that cause and where to turn it off.*
- **Windows：出包因建不了目录链接报「拒绝访问」（WinError 5）而失败**：出包和搬游戏库都不再需要建目录链接，在不让建链接的盘上也能照常出包。
  *Windows: packing failing with "access denied" (WinError 5) because a directory link could not be created. Packing and moving the library no longer need directory links, so packing works on drives that do not allow them.*
