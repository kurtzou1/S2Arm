# S2Arm v0.6.8

这是 0.6.7 的修复版：修复部分游戏首次打开时提示「地址空间不够」、无法启动；修复 Windows 认不出已连着的 iPhone；游戏中回到快照更稳；75 Hz 屏不再误降帧率档；新增 iPad 触控板 / 鼠标转视角与键位导入导出。
*A fix release for 0.6.7: some games no longer refuse to start with an "address space" notice on first launch; Windows recognizes an iPhone that is already connected; returning to a snapshot in game is more stable; 75 Hz screens no longer drop the frame-rate tier by mistake; iPad gains trackpad / mouse camera control and key-map import / export.*

## 修复
- **修复 0.6.7 上部分游戏首次打开时提示「地址空间不够」、无法启动的问题**：按已知跨度收窄地址窗口时，原先可能收到连游戏的堆都放不下；现在收窄前先算堆，放不下就不收窄；跨度只从出过画面的局里学，开局就停的局不再把窗口越收越小。
  *Fixed some games refusing to start on 0.6.7 with an "address space" notice the first time they are opened. Narrowing the address window by a known span could leave too little room for the game's heap; the heap is now checked first and the window is not narrowed if it would not fit, and spans are learned only from sessions that drew a frame.*
- **修复 Windows 认不出已连着的 iPhone**：设备号的大小写、短横写法不同也认得出；签名装机前先配对，没有配对记录时自己向手机发起。
  *Windows now recognizes a connected iPhone regardless of how the device ID is written, and pairs with the phone before a signed install when no pairing record exists.*
- **游戏中回到快照更稳**：连续回到快照不再越来越占内存、不再停在那一帧、模型不再拉丝，进程内重启后新局不读旧状态。
  *Returning to a snapshot in game no longer keeps growing memory, no longer freezes on that frame and no longer stretches models; a restart in the same process no longer reads stale state.*
- **修复 75 Hz 屏 60 帧被误判降档**：慢帧门槛按屏幕刷新拍取整。
  *60 fps on a 75 Hz screen is no longer mistaken for slow frames.*
- **修复部分游戏在 M1 Mac 上帧率掉到十几帧（出图线程被系统降级）**。
  *Fixed some games dropping to the teens in frame rate on M1 Macs because the presentation thread was demoted by the system.*
- **修复部分游戏在 Mac 长时间游玩后声音劈裂 / 爆音**：设备时钟偏快时会追上，不再慢慢吃光缓冲。
  *Fixed crackling audio after long sessions on Mac when the device clock runs fast.*
- **画面**：修复部分游戏流式压缩贴图出色块、深度模板贴图采样面选错、共享贴图被误回收；一处贴图登记锁用错引起的偶发崩溃已修。
  *Fixed color blocks in some streamed compressed textures, the wrong sampled plane for depth-stencil textures, in-use shared textures being reclaimed, and an occasional crash from a wrong lock on the texture registry.*
- **「更新这款」**：进度按这一段的已完成 / 总数 / 速度 / 还剩显示，不再停在 50%；外接盘上的游戏不再整份重编着色器库；做不齐时黄字写出真实原因；Windows 上更新期间防睡眠。
  *"Update this game" shows progress for the current stage instead of stalling at 50%, no longer rebuilds the whole shader library for games on an external drive, explains what could not be completed, and keeps Windows awake while it runs.*
- **装机与推送**：手机只连同一 Wi-Fi 时 Mac 用 Apple ID 也能装；开发者模式没开时照实提示去开；iPhone 导入不带校验码的加密 .p12 不再报读不了；Windows 读取工具被杀毒软件隔离时指去还原；组装 App 遇到文件占用会重试。
  *Installing with an Apple ID from a Mac works when the phone is only on the same Wi-Fi; a disabled Developer Mode is reported as such; encrypted .p12 files without a MAC import on iPhone; a reader tool quarantined by antivirus on Windows is reported with how to restore it; assembling the app retries when a file is in use.*
- **其他**：iOS / iPadOS 18.0.x 上开局前提示一次升级系统；Apple TV 上导入 .s2arm 不再一律被拒；资源镜像按顺序写出并显示进度；空的 RomFS 镜像保留并校验；双 Joy-Con 无线识别与左手体感方向修正；金手指偏移寄存器只在需要时改写。
  *iOS / iPadOS 18.0.x shows a one-time notice to update before a game starts; importing .s2arm on Apple TV is no longer always refused; resource images are written in order with progress; empty RomFS images are kept and verified; wireless dual Joy-Con detection and left-hand motion direction are fixed; cheat offset registers are only changed when needed.*

## 新功能
- **本地 2–4 人：多账号选人按主机的方式**。
  *Local 2–4 players: choosing users with multiple accounts now works the way it does on the console.*
- **iPad 触控板 / 鼠标转动视角**，改键页加鼠标部分，规则与 Mac 相同；**改键页可导入 / 导出键位**，文件与 Mac 启动器同格式。
  *iPad trackpad / mouse camera control with a mouse section on the key-map page, same rules as Mac; key maps can be imported and exported in the same format as the Mac launcher.*
