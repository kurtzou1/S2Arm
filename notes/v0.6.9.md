# S2Arm v0.6.9

这一版主修快照恢复：恢复不再删快照，Mac 上接不上时原地重开这一局；修复部分游戏 60 帧档两倍速；新增 iOS「分配玩家」与实体手柄改键；内存不够的设备起局前先提示。
*This release mainly fixes snapshot restore: restoring never deletes a snapshot, and on Mac a session that cannot take the snapshot in place is relaunched; some games no longer run at double speed in 60 fps mode; iOS gains "Assign players" and physical controller remapping; devices without enough memory get a notice before a game starts.*

## 修复
- **快照恢复修复：快照任何情况下都不再删除**；恢复前按快照记下的原位置重新占好内存；Mac 上接不上时原地重开这一局再恢复；游戏里接不上时先提示去游戏库恢复，不拆当前这一局；本局关着快照时从游戏库恢复不再中途失败；版本变动导致接不上时，提示可在出包页取消这款的「出包时打入」、重新出包后再恢复；旧版本（0.6.8）存下的快照，升到新版本后从游戏库恢复不再被拒。
  *Snapshot restore fixed: a snapshot is never deleted. Memory is reserved at the snapshot's original locations before restoring; on Mac, a session that cannot take the snapshot in place is relaunched and restored; in game, a snapshot that cannot be restored in place points you to the game library instead of ending the session; restoring from the library no longer fails midway when snapshots were off for that session; when a snapshot no longer fits after a change, the notice says to turn off "Add when building" for the game on the build page, rebuild, and restore again. Snapshots saved with the previous version (0.6.8) can be restored from the game library again after updating.*
- **切后台再回来后存的即时快照，恢复后界面文字、图标不再缺失**（#2086，感谢 imneway）。
  *Snapshots saved after switching away and back no longer lose on-screen text and icons when restored (#2086, thanks to imneway).*
- **修复部分游戏 60 帧档两倍速（#2053）**：社区 60 帧补丁里按目标帧率计算的变量，现在按选中的帧率写入，不再一直按 30 帧的值。
  *Fixed some games running at double speed in 60 fps mode (#2053): variables in community 60 fps patches that are computed from the target frame rate are now written for the selected rate instead of staying at their 30 fps values.*
- **修复没打更新的初版（1.0.0）开放世界大作开局不久就闪退**：iPhone / iPad / Mac 都会；修好前的绕法是打上 1.6.0 及以上的游戏更新。
  *Fixed the original 1.0.0 release of a large open-world game crashing shortly after starting, on iPhone, iPad and Mac; until now the workaround was installing game update 1.6.0 or later.*
- **修复部分大型游戏开局后玩一阵就闪退**（地址空间用尽）。
  *Fixed some large games crashing after playing for a while because the address space ran out.*
- **内存不够的设备**：判断装不装得下时按这台设备的物理内存封顶，只在菜单里待了一会儿的短局不再被当成「装得下」的依据；确实装不下时起局前问一次（本款约需多少、这台有多少、可能中途退出），不再一帧没出就被系统结束；这款以前在这台上玩过、留有实测记录时也照样提示。
  *On devices without enough memory, whether a game fits is now judged against the device's physical memory, and a short session spent in a menu no longer counts as proof that it fits; when it does not fit you are asked once before the game starts (how much it needs, how much the device has, it may quit midway) instead of being ended by the system before the first frame, including when the game has been played on this device before.*
- **修复部分游戏开局就断言退出（本机回环网络连接被拒）**：游戏内部用本机回环连接自我唤醒的，现在能照常连上。
  *Fixed some games quitting at launch with an assertion because a local loopback connection was refused: games that wake themselves through a loopback connection now connect normally.*
- **修复部分要 GLES 3 上下文的 SDL 游戏每局开局即崩（#2057）**。
  *Fixed some SDL games that need a GLES 3 context crashing at the start of every session (#2057).*
- **加载页**：着色器还在编就一直等，不再 30 秒到点硬进游戏；「先开始玩，后台继续优化」从优化画面段一开始就可点（#502）。
  *The loading page keeps waiting while shaders are still compiling instead of entering the game after 30 seconds; "Play now, keep optimizing in the background" is available from the start of the optimization stage (#502).*
- **修复部分游戏战斗时敌人血条不显示、长帧（#2051）**。
  *Fixed enemy health bars missing and long frames during battles in some games (#2051).*
- **画面**：修复贴图池在途改写导致采样读到空图闪烁（#674）；内部分辨率下部分计算着色器不再整遍退回原尺寸；遮挡查询重置、事件信号不再打断几何合批（#1449）；计算着色器常量缓冲里的采样器句柄接通（#1594）。
  *Fixed flicker from textures sampled while the texture pool table was being rewritten (#674); some compute shaders no longer fall back to native size under internal resolution; occlusion query resets and event signals no longer break geometry batching (#1449); sampler handles in compute constant buffers are now wired up (#1594).*
- **部分着色器用桌面 OpenGL 老版本写的游戏（如 Darkest Dungeon）不再有声音、没画面**；已装好的请在电脑上对这款点「更新这款」重出一次（#852，感谢 Tony-loading 反复复测）。
  *Some games whose shaders use older desktop OpenGL versions, such as Darkest Dungeon, no longer play sound over a black screen; if the game is already installed, click "Update this game" on the computer once (#852, thanks to Tony-loading for testing again and again).*
- **长时间游玩后回到去过的地方，地面不再出现一直不消失的黑块**（源自 judeyang 的 #2046）。
  *After long play sessions, revisited areas no longer show black patches on the ground that never go away (from #2046 by judeyang).*
- **修复部分游戏开局时偶发的闪退**。
  *Fixed an occasional crash when some games start.*
- **声音**：iOS 音频被打断（来电、其他 App 占用）时继续回收缓冲，游戏不再重开音频输出；恢复快照后缺失的音效状态会重建。
  *During an iOS audio interruption buffers keep being returned so the game does not reopen its audio output; missing audio effect state is rebuilt after restoring a snapshot.*
- **手柄**：iOS 外接手柄十字键不再慢半拍；手柄断开后保留玩家位、重连回到原位（#2036）；Mac 手柄状态不再与系统并发改写（#1819）；Mac 自动识别北通宙斯 NS 并补齐左摇杆（#2039）；Mac 启动设置关掉「体感」后，系统不认、靠兜底读取的手柄也不再把陀螺仪交给游戏（#1383）。
  *The D-pad on external controllers on iOS no longer lags; a disconnected controller keeps its player slot and returns to it on reconnect (#2036); Mac controller state is no longer rewritten concurrently with the system (#1819); Mac recognizes the Betop Zeus NS and its left stick (#2039); on Mac, turning off motion in launch settings also stops motion from controllers read through the fallback path (#1383).*
- **Windows 上登记过两台设备时「更新」找对连着的那台**：原先总去找记录里排第一的那台，不在线就报「这次没列出来」；现在连着的那台排第一。
  *On Windows, with two devices on record, "Update" now targets the one that's connected instead of always the first record, which failed with "not listed" when that device was offline.*
- **Apple ID 团队里还没登记设备时也能导出**：原先导出报笼统的「本地任务失败」；现在照样导出未签名的游戏包，并说清原因和下一步（连上 iPhone 推一次游戏让它登记进团队）。
  *Exporting now works even when your Apple ID team has no registered devices: instead of a generic "local task failed", it exports an unsigned game package and explains why and what to do next (connect your iPhone and push a game once so it's registered).*
- **手机报「签名证书已失效」时说清原因和办法**：原先只说「设备安装失败」；现在写明是别的签名工具刚撤了证书，或手机日期时间不对，并给出办法（打开「设置 → 通用 → 日期与时间」的自动设置后重试；S2Arm 签名前会重新核证书，被撤的换新）。
  *When the phone reports the signing certificate is no longer valid, S2Arm now explains why (another signing tool just revoked it, or the phone's date and time are wrong) and what to do (turn on automatic date and time, then retry; S2Arm re-checks the certificate before signing and replaces a revoked one), instead of a generic install failure.*
- **出包与装机**：Switch 2 版共用 Switch 1 本体 DLC 号段时不再被拒；Windows 上着色器编译超时连同子进程一起停、不再永远挂住；并发写进度文件不再让出包失败（#2034）；别的工具装的 S2Arm 比启动器旧时，接口兼容就提示后继续（#1842）；空的 RomFS 镜像保留并校验，资源镜像按顺序写出时也显示进度；「更新这款」只重算变了的部分；Apple ID 登录辅助服务器异常、硬盘读写故障、硬盘写满、长时间无进展各有自己的原因句；钥匙串里没有签名身份的证书不再算作手机上的证书。
  *Switch 2 versions that share the Switch 1 base game's DLC range are no longer refused; on Windows a timed-out shader compile is stopped with its child processes instead of hanging; concurrent writes to the progress file no longer fail a build (#2034); an S2Arm installed by another tool that is older than the launcher can continue after a notice when compatible (#1842); empty RomFS images are kept and verified, and ordered resource image writes show progress; "Update this game" recomputes only what changed; Apple ID sign-in helper errors, disk I/O failures, a full disk and long stalls each get their own reason; a certificate without a signing identity in the keychain no longer counts as the phone's certificate.*
- **推过多台手机时，「更新 S2Arm」只看连着的那台**：原先总拿记录里排第一的那台提示、甚至往没连着的那台推；现在有手机连着时提示和按钮只看连着的，Mac 也能认出连着的是哪台（#2088）。
  *If you have pushed to more than one phone, "Update S2Arm" now looks only at the phones currently connected: it no longer prompts for, or pushes to, a phone that isn't connected just because it came first in the records, and the Mac launcher now recognizes which phone is connected (#2088).*
- **D2R-Mobile 下游移植包更新到 v2.3.4**，升级后在 iPhone 上出包不再停在「登记翻译链」这一步。
  *The D2R-Mobile downstream port is updated to v2.3.4; building for iPhone after updating no longer stops at the "registering the translation chain" step.*
- **出包、更新失败时，失败原因的开头写清是什么错**，不再只剩一串调用栈的结尾。
  *When a build or update fails, the reason now starts with what went wrong instead of only the tail of a call stack.*
- **Mac 游戏库：免费签名到期只在选中游戏的设备操作区提示一次**，不再把「可在 Mac 上运行」一起标红；iPhone 版 S2Arm 有新版只在顶栏提示（源自 Xc1Ym 的 #2091）。
  *Mac game library: a free signature's expiry now shows once, in the selected game's device actions, and no longer turns "Can run on Mac" red; a new version of S2Arm for iPhone is announced only in the top bar (from #2091 by Xc1Ym).*
- **接 iPad 时不再写死 iPhone（源自 ChuBL 的 #1962）**：导出页推完程序包后的等待提示、游戏库和大图上的「已推到」都按实际设备写；0.6.9 之前装的记录写「iPhone / iPad」，重新推一次后按设备写。
  *iPad is no longer called iPhone (from ChuBL’s #1962): the wait notice on the export page after pushing a program and the "On …" status in the library and hero view name the actual device; installs from before 0.6.9 read "iPhone / iPad" until the game is pushed again.*
- **Mac 键位弹窗和进游戏用的是同一套（源自 ChuBL 的 #2081）**：这款存的键位文件坏了（不合规、缺字段、不是 JSON）时，弹窗和游戏都回到所有游戏的默认（没设过就是标准键位），弹窗照实提示读不出来；不是 JSON 时也不会再起不了局。
  *The Mac key map window and the game now use the same key map (from ChuBL’s #2081): if this game's saved key map is broken (invalid, incomplete or not JSON), both fall back to your default for all games (or the standard map) and the window says it couldn't be read; a non-JSON file no longer stops the game from starting.*
- **触屏游戏里左键仍当触屏，只要没改左键和鼠标模式（源自 ChuBL 的 #1987 / #2083）**：原先改了任何一个按键、或设了所有游戏的默认，Mac / iPad 都会判成「动过鼠标」，左键又当游戏键、点不了画面上的开始；现在只看左键绑在哪、鼠标模式是什么。
  *In touch games the left click keeps acting as a touch unless you changed the left button or mouse mode (from ChuBL’s #1987 / #2083): changing any other key or setting a default for all games no longer makes Mac / iPad treat the mouse as "changed" and stop letting you tap on-screen buttons.*
- **iPad 改键页「使用鼠标 / 触控板」开关（源自 ChuBL 的 #2072 / #2082）**：只想用键盘玩时关掉它，点触控板就当手指点屏幕（叫出虚拟按键、点画面），不再误按游戏键、不锁指针；按游戏存，可随「设为所有游戏的默认」一起设。
  *"Use mouse / trackpad" switch on the iPad key map page (from ChuBL’s #2072 / #2082): turn it off to play with the keyboard only, and a trackpad click acts like a finger tap (bringing up the on-screen controls or tapping the screen) instead of pressing a game button or locking the pointer; saved per game and included in "Set as default for all games".*
- **iPad 改键页「设为所有游戏的默认」（源自 ChuBL 的 #1987 / #2079）**：调好的一套键位一点设成所有游戏的默认，约 5 秒内可撤销；已单独调过的游戏不受影响，新加的游戏直接用这套。
  *"Set as default for all games" on the iPad key map page (from ChuBL’s #1987 / #2079): make your key map the default for every game in one tap, with about 5 seconds to undo; games you set up separately keep their own, and newly added games use it.*
- **iPad 改键页「清除按键设置」一次清掉键盘键和鼠标键（源自 ChuBL 的 #2071 / #2074）**：原先只清键盘那半，按触控板左键还会触发。
  *"Clear key settings" on the iPad key map page now clears both the keyboard key and the mouse button (from ChuBL’s #2071 / #2074); it used to clear only the keyboard half, so the trackpad click still triggered the button.*
- **「更新这款」做不齐时说清楚原因，缺原件可以就地补（源自 ChuBL 的 #1961）**：分清是没装 Metal 开发工具、要在出包页重新出包，还是原件也不在；原件不在时黄字下给「重新添加原件…」，只认这一款，选错了不改游戏库。
  *"Update this game" now says why it couldn't finish, and you can re-add a missing original right there (from ChuBL’s #1961): it tells apart missing Metal tools, a needed rebuild on the build page, and a missing original; for the last, "Re-add original…" appears under the notice, accepts only this game, and leaves the library unchanged if you pick a different one.*
- **Mac 首页「S2Arm」卡按上次装的设备画 iPad / iPhone（源自 ChuBL 的 #1967）**：不用等点进去现查；不知道是哪种时画通用设备图标；选中后卡片上放 S2Arm 图标。
  *The "S2Arm" card on the Mac home page draws iPad or iPhone from the last install instead of waiting for a live check (from ChuBL’s #1967); an unknown device gets a generic icon, and the selected card shows the S2Arm icon.*
- **Mac 存档页说清楚（源自 ChuBL 的 #2066）**：写明这一页管的是这台 Mac 上的存档；没在这台 Mac 上玩过的游戏，恢复的存档会显示「已放好 N 个文件，第一次在这台 Mac 上启动时放进存档」，可以「不要了」；访达压的 zip 不再带进 `__MACOSX`。
  *Mac save page is clearer (from ChuBL’s #2066): it says it manages the saves on this Mac; for a game never played on this Mac, a restored save shows as waiting to go in the first time you start the game here, and can be discarded; zips made by Finder no longer bring in `__MACOSX`.*
- **iOS 设置里给 S2Arm 单独选的语言全都生效（源自 ChuBL 的 #2069）**：系统是英文、在「设置 → S2Arm → 语言」选了中文时，存档报错、诊断上传等提示也跟着出中文，不再中英混杂。
  *Language chosen for S2Arm in iOS Settings now applies everywhere (from ChuBL’s #2069): with the system in English and S2Arm set to Chinese, save errors and diagnostic upload notices follow the app language too.*
- **其他**：修复一款游戏补丁表竞争导致的偶发崩溃；安卓上出包预编库前后两段接口对不上时退回现编，分离采样器来源不再丢失。
  *Fixed an occasional crash from a race on one game's patch table; on Android, prebuilt pipelines whose stages do not match fall back to compiling on device, and separate sampler sources are kept.*

## 已知变化
- **iOS 26 上少数大型游戏不能存快照**：这些游戏要用的地址范围比系统给 App 的多，放不下快照，游戏内菜单里会写明原因（和存储空间无关，游戏照常能玩）；之前存下的快照照样可以从游戏库恢复。
  *On iOS 26 a few large games cannot save snapshots: they need more address range than the system gives an app, so there is no room for a snapshot. The in-game menu explains why (it is not about storage, and the game plays normally); snapshots saved earlier can still be restored from the game library.*

## 新功能
- **iPhone / iPad 游戏库设置新增「游戏来源」**：把电脑导出的游戏（.s2arm 和 .img）放在外接硬盘等文件夹里，直接从那里玩，不用拷进手机；Mac 游戏库也放在这块盘上时，一块盘两端通用。硬盘要用 APFS 格式；没接上时游戏显示为灰色，接上自动恢复。
  *New on iPhone and iPad: Game sources in the library settings. Put games exported from the computer (.s2arm and .img) in a folder, for example on an external drive, and play them from there without copying them in; with the Mac game library on the same drive, one drive works for both. The drive needs to be APFS; while it isn't connected, its games show greyed out and come back when it is.*
- **iPhone / iPad「存档管理」能导入其他模拟器 / 工具的存档（源自 ChuBL 的 #2070）**：「选择备份并检查…」除了 S2Arm 的 .s2asave，也能选 JKSV、Checkpoint、Ryujinx、yuzu 等的存档文件夹或 zip；确认后先备份当前存档，下次开始游戏时读入。只选了单个存档文件或认不出时会说清楚原因。
  *"Manage saves" on iPhone / iPad can import saves from other emulators and tools (from ChuBL’s #2070): besides S2Arm .s2asave backups, "Choose a backup to check…" accepts a save folder or zip from JKSV, Checkpoint, Ryujinx, yuzu and others; your current save is backed up first and the new one is loaded the next time you start the game. Picking a single save file or an unrecognized save now explains why.*
- **iOS「分配玩家」与实体手柄改键**（源自 Ting2024 的 #1606）：游戏内齿轮菜单「分配玩家…」，在哪只手柄上按一下键就登记成下一位玩家，与 Mac 同一份顺序表；实体手柄按这一款的键位改键。
  *iOS "Assign players" and physical controller remapping (from Ting2024's #1606): choose "Assign Players…" in the in-game gear menu and press a button on each controller to register players in order, using the same order table as Mac; physical controllers follow the game's key map.*
- **Mac 手柄**：关掉「切到别的窗口时暂停」后，切到别的窗口手柄照样操作游戏；启动器录键可以录修饰键组合；分配玩家时兜底读取的手柄接上即加入（#1151）。
  *Mac controllers keep controlling the game in other windows when "Pause when switching away" is off; the launcher can record modifier-key combinations; controllers read through the fallback path join as soon as they connect when assigning players (#1151).*
- **Mac 可直接把游戏与 Mod 推到 LiveContainer**，并显示导入与删除状态（#2010、#2012）。
  *Mac can push games and mods directly to LiveContainer and shows import and removal status (#2010, #2012).*
